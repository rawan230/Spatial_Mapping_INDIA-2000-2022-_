# Supplementary comparison charts (added 30 Sep 2026)

These two charts replace the informal request for an updated version of the old
model-comparison plot (`Biswas_Comparison_Figures/` era: `Fig10_Jackknife_BarChart.png`
and an equivalent ROC/PR-curve comparison), which used a different, superseded model
roster (LogReg/RF/XGBoost/PlainMLP/PINN) and numbers that no longer match the current
pipeline.

They are **not** wired into `results/code/make_figures.py` and will not be
regenerated by it — treat them as a one-off addition until/unless folded into that
script. Provenance for each:

- **`model_comparison_tracks_A_B1_B2.png/.pdf/.csv`** — CDR-PINO (full/no-physics),
  Logistic Regression, MaxEnt, Random Forest, ROC-AUC on Tracks A/B1/B2, matched
  12 km cells/partitions/covariates. Track A values verified directly against
  `results/final/FINAL_METRICS.csv` (tracks `CDR_A`, `bridge12_A`); Track B1/B2
  values are transcribed from the manuscript's own Table VI (`bridge12_B1`/`bridge12_B2`
  rows for the `_cdr7` classical models were not present in `FINAL_METRICS.csv` at
  the time of writing — if they're added later, this chart should be rebuilt from
  them directly rather than from the manuscript text).

- **`track_B3_AUC_vs_AP.png/.pdf/.csv`** — every number read directly from
  `results/final/FINAL_METRICS.csv` (tracks `CDR_B3`, `bridge12_B3`, population
  `all`). This is a genuinely new figure, not a redraw of an existing one: it puts
  AUC and AP for the same six comparators side by side and shows that AUC (0.89–0.97
  across the board) makes the operator look competitive with RF+month and the
  seasonal-persistence baseline, while AP (0.14–0.55) shows the operator is actually
  far behind both. The manuscript's Table VI reports the AUC numbers but does not
  carry the AP comparison through for this set of comparators — worth considering
  for inclusion in the manuscript itself, since it's a sharper illustration of the
  paper's own point about ranking metrics compressing a gap that precision-based
  metrics expose.
